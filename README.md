# 🌿 AQUALO — E-commerce & Landing Pages

Sitio web oficial y plataforma de comercio electrónico para **AQUALO**, una marca argentina especializada en el cuidado capilar y bienestar personal (tratamientos anticaída, dermocosmética y filtración de agua) con respaldo regulatorio ANMAT.

---

## 📂 Estructura del Proyecto

El proyecto está desarrollado con páginas independientes conectadas entre sí y componentes reutilizables:

```text
/
├── index.html          # Página principal / Inicio con propuesta de valor y productos destacados
├── catalogo.html       # Catálogo completo de productos de la línea capilar y accesorios
├── about.html          # Sección "Quiénes Somos" con la historia y filosofía de la marca
├── anmat.html          # Respaldo regulatorio, certificaciones ANMAT y prueba social
├── mayoristas.html     # Sección B2B para distribuidores, farmacias, peluquerías y emprendedores
├── contacto.html       # Tarjeta gigante de contacto con formulario integrado (FormSubmit) y redes
├── politicas.html      # Políticas de envío, devolución y términos del servicio
├── css/
│   └── styles.css      # Estilos personalizados, paleta de colores y tipografías corporativas
└── js/
    └── main.js         # Lógica global del sitio (interacciones, navegación y menús)
